งานแบบไหนควรเลือก Llama 3.3 70B Instruct (API) แทนที่จะจ่ายแพงกว่าใช้ Claude 3.7 Sonnet?

การเปิด Prompt Caching ช่วยลดบิลของ Claude 3.7 Sonnet และ Llama 3.3 70B Instruct (API) ลงได้แค่ไหน?
